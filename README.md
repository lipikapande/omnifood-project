# Omnifood

## Overview

Omnifood is a front-end landing page for a meal-subscription service that promotes healthy, convenient food delivery. The project presents the service’s value proposition, explains how the subscription works, highlights meal options and pricing, and includes testimonials and a sign-up call to action.

## Highlights

- Presents a polished one-page experience for a food delivery product with clear sections for value, process, meals, testimonials, pricing, and signup.
- Includes responsive design behavior for desktop and mobile layouts, including a mobile navigation toggle and smooth in-page scrolling.
- Uses a progressive web app manifest and web assets to support a more app-like browsing experience.
